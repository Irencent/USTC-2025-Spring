# 第7章 图像压缩复习笔记

## 1. 压缩概述

* **目的**：减少存储空间、缩短传输时间。
* **分类**：

  * 无损压缩（Reversible）：完全可恢复原始数据。
  * 有损压缩（Irreversible）：舍弃部分信息以换取更高压缩率。
* **冗余类型**：

  1. **编码冗余**：符号编码长度与信息熵之差。
  2. **空间冗余（像素冗余）**：邻域像素相关性。
  3. **视觉冗余**：人眼不敏感的细节可舍弃。

## 2. 基本概念与理论

### 2.1 自信息与熵

* **自信息**：事件 $E$ 发生时所含信息量
  $I(E) = -\log_2 P(E)$
* **源熵**：离散随机变量 $X\{x_i\}$ 熵
  $H(X) = -\sum_{i} P(x_i) \log_2 P(x_i)$

  * 当各符号等概率时 $H(X)=\log_2 N$。

### 2.2 香农定理

* **无噪声信源编码定理**：最优编码平均码长满足
  $H(X) \le L_{avg} < H(X) + 1.$
* **有失真率失真极限**：给定失真度 $D$，速率失真函数
  $R(D) = \min I(X;\hat X) \le H(X).$

## 3. 熵编码

### 3.1 霍夫曼编码（Huffman）

1. 按概率升序两两合并，构造编码树。
2. 低概率符号分配长码字，高概率符号分配短码字。
3. 平均码长：
   $L_{avg} = \sum_k p(r_k) \ell(r_k).$

### 3.2 算术编码（Arithmetic）

* 将整个符号序列映射到区间 \[0,1)，利用累计概率不断缩小区间。
* 输出任意一个落在最终区间内的实数。

## 4. 二值图像编码

1. **常量面积编码**：三类区域（全白、全黑、混合）分别编码。
2. **游程编码（RLE）**：记录行内黑白像素的连续长度。
3. **轮廓跟踪编码**：记录轮廓行间起始位置和长度差分。

## 5. 预测编码

### 5.1 无损预测

* **线性预测模型**：
  $\hat f_n = \mathrm{round}\Bigl(\sum_{i=1}^m \alpha_i f_{n-i}\Bigr),$
  其中 \\(\alpha\_i\\) 为预测系数。
* 残差编码后再进行熵编码。

### 5.2 有损预测（DPCM）

* 最小化均方预测误差：
  $\min \mathbb{E}\{(f_n-\hat f_n)^2\}.$
* 常见预测模板如左、上、左上像素的加权组合。
* 量化函数（阶梯量化）：
  $\tilde e = Q(e) = \mathrm{round}(e/T) \times T.$

## 6. 变换编码

### 6.1 图像变换

* **常用变换**：离散傅里叶变换（DFT）、离散余弦变换（DCT）、Karhunen–Loève 变换（KLT）、小波变换（WT）。
* **性质**：能量集中、去相关。

### 6.2 编码流程

1. 分块（如 8×8）。
2. 正向变换：$Y = T\,X\,T^T$。
3. 量化：
   $Z(u,v) = \mathrm{round}\bigl(\frac{Y(u,v)}{Q(u,v)}\bigr).$
4. 熵编码（Zig-Zag 扫描 + RLE +  霍夫曼/算术）。
5. 解码时逆向操作。

### 6.3 JPEG 标准

* 默认 8×8 DCT。
* 标准量化表 $Q(u,v)$，可根据质量因子调整。
* 阈值（Thresholding）决定零系数量。
* 马赛克块效应：块间量化差异导致边缘失真。

## 7. 国际标准一览

* **图像**：JPEG、JPEG2000
* **视频**：MPEG-1/2/4、H.261/H.263/H.264/HEVC
